# Bobber's Journal

A fishing journal and fishing improvements for World of Warcraft (Forever and Retail).

## Features
- Records every cast: catches, failed and aborted casts, zone and spot, coordinates, lure, fishing skill, buffs and time spent fishing.
- Journal in book design: fish, junk, lures, zones with an ink-style map of your fishing spots, search and bookmarks.
- Cast by double click or key (off by default), optional automatic lures and weapon swap on Forever.
- Fishing tooltip with a skill bar split into skill, lure, equipment and buffs; fishing data on caught items.
- TomTom support: set waypoints and routes to your fishing spots.
- Minimap button, addon compartment entry and a bobber display you can move in Edit Mode.
- API for other addons.

## Status
Alpha. Not everything is tested in the game client yet.

Source and issues: https://github.com/N3zr0k/BobbersJournal
